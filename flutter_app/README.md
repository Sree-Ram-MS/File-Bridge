# FileBridge for Android

Flutter app that turns the phone into a FileBridge host. It runs the same HTTP API and
web explorer as the desktop app, so any browser on the network can connect and request access.
The owner approves devices, picks permissions and changes the shared folder in the app.

## Build

```bash
python3 tools/export_web.py                  # from repo root: copy the web UI into assets/web
cd flutter_app
flutter create --org com.sreeram --project-name filebridge --platforms android .
rm -rf test
pip install pillow && python3 tool/setup_android.py   # permissions, app name, icon
flutter pub get
flutter build apk --release                  # build/app/outputs/flutter-apk/app-release.apk
```

The `android/` folder is generated by `flutter create`, so it always matches your Flutter version.
CI does the same steps on every push to the `android` branch and attaches the APK to the release.

## Notes
- Needs "All files access" (Android 11+) so others can browse shared storage.
- Keep the app open while sharing. Android may pause it in the background.
- The release APK is signed with a debug key, so installing a newer build may need uninstalling the old one first.
