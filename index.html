Why FileBridge

Like http.server, minus the worry

Typing one Python command to share files with the next desk is handy. It also lets anyone on the network read everything in that folder, and nobody can send files back.

python3 -m http.server

The quick way
  • Anyone on the Wi‑Fi can read the folder
  • Download only, no way to send files back
  • A bare list of links, no previews
  • You have to look up your own IP
  • Needs a terminal on every machine

FileBridge

The same idea, done properly
  • Every device asks, and you approve it
  • Uploads, new folders, rename and delete, if you allow them
  • A real explorer with thumbnails and previews
  • Your address is on screen, ready to share
  • A real app on Ubuntu and Android, one double-click on Windows

How it works

Three steps, then it just works

No accounts, no cloud, no app on the other side. Files go straight from one device to the other over your own network.

Start sharing

Open FileBridge and pick a folder. It shows your address on the dashboard.

http://192.168.1.24:8000

They ask for access

On the same Wi‑Fi, they open that address in any browser, type a name and tap Request access.

Anu's laptop
Request access

You approve

Their request pops up on your dashboard. Pick what they can do and approve. Their browser opens your folder.

Approve
Their browser→Your Wi‑Fi→FileBridge on your device→Your folder

Approved devices are remembered, so next time they open the address and go straight in. Both of you can run FileBridge to share in both directions.

Permissions

Three levels, per device

Give the intern view-only access and your teammate full control, at the same time. Change it or remove someone whenever you like.

View & download

For anyone who just needs a file from you.

  • Browse, search and preview
  • Download files
  • Download whole folders as ZIP

View & upload

For people sending work back to you.

  • Everything in View
  • Upload files and whole folders
  • Create new folders

Full access

For people you trust with the folder.

  • Everything in Upload
  • Rename files and folders
  • Delete files and folders

Nobody can see anything outside the folder you share, and the device doing the sharing always has full control.

Features

A file explorer, not a list of links

The people you approve get a proper explorer in their browser, on a phone or a PC.

Preview before you download

Images, video, audio, PDFs, text and code open right in the browser. Video seeks instantly, even in big files.

3:05

Drag and drop uploads

Drop files or whole folders in. Progress shows for each one, and nothing is overwritten.

Grid or list

Thumbnails for photos, or a tidy list with sizes and dates. Sort by name, size or date.

Search and breadcrumbs

Find a file as you type, and jump back up the folder path in one tap.

Folders as ZIP

Grab a whole folder in one download. The ZIP streams as it builds, so big folders start right away.

Copy a link

Send a direct link to one file. It only opens for devices you've approved.

Light and dark

Follows the system theme on every device, phone or desktop.

Requests on your phone

On Android, a notification tells you when someone asks to connect, and sharing keeps running with the screen off.

Download

Get FileBridge for your device

Install it on the device that shares the files. Everyone connecting only needs a browser.

Windows 10 and 11

One portable .exe, about 8.8 MB. No installer, no Python needed.
  1. Download FileBridge-0.1.0-windows-x64.exe.
  2. Double-click it. If SmartScreen appears, choose More info, then Run anyway.
  3. At the firewall prompt, allow it on Private networks.
  4. The dashboard opens in your browser with your address. It shares your Downloads folder until you pick another.
The app isn't code-signed yet, which is why Windows asks once before running it.
Download .exe v0.1.0 · x64

Ubuntu and Debian

A .deb that opens FileBridge in its own app window. No terminal, no browser tab.
  1. Download filebridge_0.1.0_all.deb.
  2. Install it:
    sudo apt install ./filebridge_0.1.0_all.deb
  3. Open FileBridge from the app menu. The dashboard opens in its own window, and closing it stops sharing.
  4. Files you download from a friend save to Downloads, with a notification for each.
Prefer the terminal? Run filebridge ~/folder. If UFW is on, open the port once: sudo ufw allow 8000/tcp
Download .deb v0.1.0 · all architectures

Android 7 and newer

A 68 KB app that turns your phone into a FileBridge host.
  1. Download FileBridge-0.1.0-android.apk on your phone and open it.
  2. If asked, allow installing apps from your browser or file manager.
  3. Open FileBridge and allow All files access and notifications.
  4. Share the address on screen. Requests arrive as notifications, and sharing keeps going until you tap Stop sharing.
Want to connect to someone else's FileBridge from your phone? You don't need the app for that, just your browser.
Download .apk v0.1.0 · 68 KB

Any OS with Python 3.8+

One file, standard library only. Works on macOS, Linux, Windows and even a Raspberry Pi.
  1. Download and unzip FileBridge-0.1.0-portable.zip.
  2. Run it with the folder you want to share:
    python3 filebridge.py ~/Downloads
  3. The dashboard opens at localhost:8000/admin.
# more options python3 filebridge.py . --port 9000 --no-browser

Connecting to someone's FileBridge

iPhone, Android, Windows, Mac, Linux, a tablet: anything with a browser.
  1. Join the same Wi‑Fi or hotspot as the sharing device.
  2. Type the address they show you, like 192.168.1.24:8000, into your browser.
  3. Enter a name for your device and tap Request access.
  4. Once they approve, their folder opens. Next time you go straight in.

Privacy and safety

Your files never leave your network

There's no FileBridge server, account or cloud. Files travel straight between the two devices on your own Wi‑Fi.

Like http.server, traffic is plain HTTP. Use FileBridge on networks you trust, such as your office or home Wi‑Fi, not public hotspots.
Approval first

No one sees a single file until you approve their device.

Locked to one folder

Paths that try to escape the shared folder are blocked.

Revoke anytime

Remove a device and its access ends on its very next click.

Safe uploads

Uploads never overwrite files, and half-finished ones are cleaned up.

Open source

One core, a branch per platform

The core is a single Python file with no dependencies. Each platform lives on its own branch, and GitHub Actions builds every package into the release.

Questions

Before you install

Do the other people need to install anything?

No. They open your address in any browser, on a phone or a computer. Only the device sharing the files runs FileBridge.

Does it work without internet?

Yes. It only needs a local network: office Wi‑Fi, home Wi‑Fi, or a phone hotspot both devices are on.

Can two people share with each other?

Yes. Both run FileBridge and approve each other. The dashboard also has a box to open someone else's address.

My colleague can't connect. What should I check?

Make sure you're on the same network, and that the address includes the port, like :8000. On Windows, allow FileBridge on Private networks. On Ubuntu with UFW, run sudo ufw allow 8000/tcp. Some guest Wi‑Fi networks block devices from seeing each other.

Is there a file size limit?

No set limit. Uploads and downloads stream, so large videos and backups work. Folder ZIPs are best kept under 4 GB on Android.

Why does Windows warn me before it runs?

The executable isn't code-signed yet, so SmartScreen asks once. Choose More info, then Run anyway. The full source is on GitHub.

Why does the Android app need All files access?

So approved devices can browse and upload into the folder you choose, such as Downloads or DCIM. FileBridge only exposes the one folder you share.

Is it safe on public Wi‑Fi?

Not recommended. Traffic is plain HTTP, like python3 -m http.server. Approval keeps strangers out, but use trusted networks for anything sensitive.
